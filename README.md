# 間取りメモ PWA

iPhoneで間取り・寸法・家具配置をオフライン確認するための静的PWAです。

## プライバシー方針

- `dist/` は公開可能な汎用アプリだけを含みます。
- 実際の図面、室内写真、採寸データは `private-data/` または端末内のIndexedDBだけに置きます。
- `private-output/` はGit管理から除外され、GitHub Pagesへは送信されません。
- 外部API、アクセス解析、広告、外部CDNは使用しません。
- 実データはJSONとしてiPhoneの「ファイル」から読み込みます。
- アプリ更新やGitHub Pagesへの再配信は、iPhoneの「ファイル」にある元のJSONを編集しません。読み込み後の編集内容はSafari内の別コピーに保存されます。

## GitHub Pagesへの配信

`main` ブランチへ更新を送ると、GitHub Actionsがテストと公開境界検査を実行し、合格した場合だけ `dist/` をGitHub Pagesへ配信します。公開許可リストにないファイルが `dist/` に入ると配信は停止します。

iPhoneでは同じ公開URLを開くと更新を確認し、新しいアプリが準備できた時点で自動的に一度だけ再読み込みします。更新が見えない場合は、ホーム画面へ追加したアプリを一度終了して開き直します。端末内へ読み込んだ間取りデータはアプリ更新後も保持されます。

## ローカル確認

静的ファイルをHTTPサーバーで配信し、`dist/` を開いてください。Service WorkerはHTTP/HTTPS上でのみ動作します。

## データ形式

アプリ用データは `floorplan-pwa/v1` 形式です。空データと架空のサンプルはアプリ内で生成できます。実測データ変換物は公開ディレクトリに置きません。
